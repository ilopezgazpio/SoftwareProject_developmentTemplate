## 4. Definition of done for this sprint

A task is done when:

- its result is in the repository and linked from the issue;
- another member has read it and left a comment on the issue;
- the Product Owner accepts it against the confirmed requirement it serves, if any;
- the issue is closed and the board shows it in Done.
